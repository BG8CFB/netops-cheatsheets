交换机密码忘记 — 三厂商 Console 口恢复完整步骤

H3C Comware · 华为 VRP · 思科 IOS。前提：你有设备的物理接触权和 Console 线（这是设备管理员的官方恢复路径，各厂商文档均有记载）。

通用准备

项要求
Console 线USB 转 RJ45 或原配串口线
终端软件SecureCRT / Xshell / PuTTY，波特率 9600（华为 BootROM 可能需改 115200，见下文）
窗口期重启后几秒内按键进 BootROM，错过重来

H3C（Comware V5/V7）— BootROM 跳过配置

# 1. Console 连接，重启设备
reboot
# 2. 出现 "Press Ctrl+B to enter Boot Menu" 时按 Ctrl+B
#    （V7 部分型号提示 Press Ctrl+C，按提示来）
# 3. BootROM 菜单选 4（或按菜单序号）: Skip Current Configuration File
# 4. 再选 0 或 Reboot 重启 —— 设备以空配置启动，原配置仍在 flash
# 5. 空配置下进入系统视图，把 flash 里的原配置拷回来改密码：
copy flash:/startup.cfg backup-old.cfg
# 6. 直接改本地用户密码：
local-user admin
 password hash New_Str0ng_Pass!
quit
save force
V7 细节：BootROM 密码默认为空直接回车；若设过 BootROM 密码且也忘记 → 只能 RMA 或按厂商流程处理。

华为（VRP）— BootROM 修改密码

# 1. Console 连接（BootROM 阶段波特率注意提示，多为 115200）
reboot
# 2. 提示 "Press Ctrl+B to enter BootROM menu" 按 Ctrl+B
# 3. 选 5 (或对应项): Startup Configuration / 或 Password Manager
#    部分版本: 选 "Modify BootROM password" 或 "Clear password for console user"
# 4. 选清除 console 密码后重启，进入系统改新密码：
aaa
 local-user admin password irreversible-cipher New_Str0ng_Pass!
 local-user admin privilege level 15
quit
save

思科（IOS）— Password Recovery

# 1. 拔电，按住面板 Mode 键，插电，等 status 灯闪烁松手
#    （老型号 2960: 按住 MODE 上电 5 秒）
# 2. 出现 switch: 提示符，初始化 flash 文件系统：
switch: flash_init
# 3. 改配置寄存器跳过启动配置（或改名启动配置）：
switch: rename flash:config.text flash:config.old
switch: boot
# 4. 进入后问是否进 setup，答 no；进特权模式：
enable
# 5. 恢复原配置但改密码：
rename flash:config.old flash:config.text
copy flash:config.text running-config
configure terminal
 username admin privilege 15 secret New_Str0ng_Pass!
 line con 0
  password New_Console_Pass!
 end
write memory

恢复出厂（兜底，配置全丢）

厂商命令前提
H3Crestore factory-default（V5）/ 空配置启动后 reset saved-configuration 再重启能登录
华为reset saved-configuration + reboot能登录
思科write erase + reload能登录

预防比恢复省事：把所有设备配置定期自动备份，改密码前先备份。开源工具 netcfg-vault 可 SSH 批量备份 H3C/华为/思科/锐捷配置（免费 5 台）。相关阅读：SSH 开启配置 · 30 任务命令总对照表。

流程基于各厂商官方文档整理，型号差异以设备 BootROM 实际菜单为准。
