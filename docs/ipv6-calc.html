/32ffff:ffff::2^96ISP 初始分配
/48ffff:ffff:ffff::2^80站点分配（企业/园区）

/128ffff:...:ffff1主机地址/回环

IPv6 压缩规则速记

① 每组前导零省略：0db8 → db8
② 连续全零组用 :: 替代（只能用一次）：2001:0db8:0000:...:0001 → 2001:db8::1
③ fe80::/10 是链路本地，ff00::/8 是组播，2000::/3 是全球单播
④ ::1 回环，:: 未指定地址
