BGP / OSPF 排障速查

5 大高频故障 · 逐项根因清单 · 三厂商命令 — 按 checklist 逐条排除

BGP 邻居起不来 (Idle / Active 反复跳)

诊断命令
display bgp peer  # H3C/华为
show ip bgp summary  # 思科
检查 1: TCP 179 通不通
ping <对端> / telnet <对端> 179
acl 只放行 179 是常见漏配点
检查 2: peer 地址配错
peer 10.1.1.2 as-number 65001  # 两边 AS 必须互认
检查 3: 源接口不匹配
华为: peer 10.1.1.2 connect-interface LoopBack0
思科 ebgp 多跳: neighbor 10.1.1.2 ebgp-multihop 2
检查 4: 多线 eBGP
peer 10.1.1.2 permit-asloop / local-as 配置不当

BGP 邻居 Established 但收不到路由

看收发统计
display bgp peer <ip> verbose  # 收到/发布的 prefix 数
检查 1: 路由策略过滤
display current | include peer.*route-policy
route-policy 里 deny 了入方向
检查 2: iBGP 水平分割
iBGP 学到的路由不再传 iBGP → 需要 RR 或全互联
检查 3: next-hop 不可达
iBGP 传的路由 next-hop 不变 → 对端没有 IGP 路由到 next-hop
peer x.x.x.x next-hop-local
检查 4: 同步 AS_PATH
本端 AS 在收到的 AS_PATH 里 → peer x.x.x.x permit-asloop

OSPF 邻居卡在 ExStart / Exchange

诊断命令
display ospf peer  # 看 state
show ip ospf neighbor  # 思科
原因 1: MTU 不一致
接口 MTU 在 DD 报文里携带, 不一致就卡 ExStart
华为/H3C: ospf mtu-enable 开启检测 (默认关)
原因 2: HELLO/DEAD 不匹配
hello 10s dead 40s 两边必须一致
网络类型不一致 (broadcast vs p2p) 也报这个
原因 3: 区域 ID/认证不匹配
area 0 vs area 1; 认证模式/密钥不同

OSPF 邻居 Full 但路由没学到

检查 1: LSU 没来
display ospf lsdb  # 看有没有对端的 LSA
检查 2: 末梢区域
stub/nssa 区域不收 5 类 LSA (外部路由)
检查 3: 路由过滤
filter-policy import acl 2000  # import 方向过滤了
检查 4: 转发地址
5 类 LSA 的 forwarding-address 不可达 → 路由不装表

STP 拓扑震荡 / 根桥漂移

看当前根
display stp root  # 根桥 MAC 变了就是漂移
检查 1: 新接入交换机优先级更低
新设备默认优先级 32768 带 MAC 更小 → 抢根
防御: 主干交换机 stp priority 4096 (更小=更优先)
检查 2: TCN 风暴
display stp tc  # TC 报文持续增长 → 终端口没开 edge
防御配置
端口: stp edged-port enable + bpdu-drop any (华为/H3C)
全局: stp tc-protection
