交换机上快速过滤端口流量

# H3C / 华为 (VRP): 抓包过滤端口
display packet-filter  # 查看ACL
# 思科: 查看哪些端口在跑
show ip sockets        # 路由器
show control-plane host open-ports  # 交换机
# 通用: Linux 服务器侧排查
ss -tunap | grep -E ":(22|161|514|443) "

高危端口加固清单

🔴 23 Telnet → 关闭, 换 SSH (三厂商命令见 SSH 开启教程)
🔴 6379 Redis → 必须设密码 + bind 内网
🔴 3389 RDP / 445 SMB → 禁止暴露公网, 走 VPN
🟡 80 HTTP / 8080 → 管理页换 443
🟡 161 SNMP v2c → 换 v3 或加 ACL (见 SNMP 配置教程)
