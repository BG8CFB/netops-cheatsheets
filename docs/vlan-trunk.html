完整示例：单臂互联两台交换机

# H3C 接入交换机
vlan 10
vlan 20
interface GigabitEthernet1/0/1
 port link-type access
 port access vlan 10
interface GigabitEthernet1/0/24
 port link-type trunk
 port trunk permit vlan 10 20

# 华为核心交换机
vlan batch 10 20
interface Vlanif10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0/1
 port link-type trunk
 port trunk allow-pass vlan 10 20

# 思科核心交换机
vlan 10
vlan 20
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface GigabitEthernet1/0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20
常见错误：① 思科先配 trunk 模式前需 switchport trunk encapsulation dot1q（老设备）；② 两端 native/pvid VLAN 不一致会产生跨 VLAN 泄漏；③ 华为 port default vlan 只对 access 口生效；④ H3C trunk 默认只放行 VLAN 1，忘记 permit 是通病。
排查顺序：PC ping 网关 → display mac-address / show mac address-table 看 MAC 学到没有 → 查 access VLAN 归属 → 查 trunk 放行列表 → 查网关 SVI 状态。
