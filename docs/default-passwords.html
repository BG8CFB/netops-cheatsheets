首次登录后必做 3 步（以 H3C/华为为例）

# 1. 改本地用户密码
local-user admin
 password cipher 你的强密码

# 2. 关 telnet 开 SSH
undo telnet server enable
ssh server enable

# 3. VTY 限 SSH + 绑 ACL（只放行管理段）
acl 2001
 rule permit source 192.168.10.0 0.0.0.255
user-interface vty 0 4
 acl 2001 inbound
 authentication-mode ssh

思科等价命令见 SSH 安全配置专题；SNMP 团体字加固见 SNMP v3 配置。

忘记密码了？

Console 密码丢失走 BootROM：H3C Ctrl+B 选跳过配置启动 → 保留配置改密码；华为类似；思科 Mode 键 + rename flash:config.text。完整步骤见 交换机密码恢复专题。
