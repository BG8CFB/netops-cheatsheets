交换机开启 SNMP — 三厂商完整配置（v2c / v3）

H3C Comware · 华为 VRP · 思科 IOS。监控平台（Zabbix / LibreNMS / PRTG）采集交换机前必须先开 SNMP。

H3C（Comware V7）

# v2c（简单，内网可用）
snmp-agent
snmp-agent community read Read0nly
snmp-agent community write Write0nly
snmp-agent sys-info version v2c
snmp-agent target-host trap address udp-domain 192.168.1.100 params securityname Read0nly v2c
snmp-agent trap enable

# v3（推荐：认证+加密）
snmp-agent
snmp-agent group v3 netops privacy read-view ViewDefault
snmp-agent usm-user v3 monitor netops simple authentication-mode sha Auth-Pass-123 privacy-mode aes128 Enc-Pass-456
snmp-agent trap enable

华为（VRP）

# v2c
snmp-agent
snmp-agent community read @{%@%}Read0nly@{%@%}
snmp-agent sys-info version v2c v3
snmp-agent target-host trap address udp-domain 192.168.1.100 params securityname Read0nly
snmp-agent trap enable

# v3
snmp-agent
snmp-agent group v3 netops privacy
snmp-agent usm-user v3 monitor netops authentication-mode sha Auth-Pass-123 privacy-mode aes128 Enc-Pass-456
snmp-agent trap enable

思科（IOS）

# v2c
snmp-server community Read0nly RO
snmp-server location IDC-Core
snmp-server enable traps
snmp-server host 192.168.1.100 version 2c Read0nly

# v3（推荐）
snmp-server group NETOPS v3 priv
snmp-server user monitor NETOPS v3 auth sha Auth-Pass-123 priv aes 128 Enc-Pass-456
snmp-server enable traps
snmp-server host 192.168.1.100 version 3 priv monitor

Zabbix 对接参数速查

项v2cv3 (authPriv)
宏{$SNMP_COMMUNITY}{$SNMP_SECNAME} / {$SNMP_AUTHPASS} / {$SNMP_PRIVPASS}
安全级别—authPriv（SHA + AES128）
上下文—v3 无 context 除非 VRF
验证snmpwalk -v2c -c Read0nly IP sysUpTime / snmpwalk -v3 -u monitor -l authPriv -a SHA -A ... IP sysUpTime
安全加固：① 永远别用 public/private 默认团体字；② 团体字别用弱字典词；③ 优先 v3 authPriv；④ 用 ACL 限定 NMS 源 IP：
H3C snmp-agent community read Read0nly acl 2000 / 华为同式 / 思科 snmp-server community Read0nly RO 10（10 为标准 ACL）

更多三厂商对照：30 任务命令总对照表 · SSH 开启专页 · VLAN/Trunk 专页。批量审计 SNMP 弱配置可用 netcfg-vault audit。

基于 Comware V7 / VRP / IOS 15.x 整理。
